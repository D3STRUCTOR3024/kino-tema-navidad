# 🎄 Tema Kino TV - Navidad 

Un tema festivo y elegante diseñado para celebrar la temporada en la aplicación Kino TV. Transforma la interfaz con un logotipo rediseñado que incluye un árbol de Navidad, copos de nieve y un hermoso degradado nevado.

## ❄️ Características
* **Fondo Nevado:** Un degradado suave que pasa de blanco puro en la parte superior a verde pino en la parte inferior, ideal para una lectura cómoda.
* **Logotipo Navideño:** Letras personalizadas donde la "i" es un árbol de Navidad completo. Decorado con sutiles copos de nieve celestes.
* **Superficies Claras:** Paneles y tarjetas en tonos blanco menta para mantener la frescura del invierno.
* **Colores Personalizables:** Aunque el rojo navideño es el color por defecto, puedes cambiar el acento (incluyendo la estrella del árbol) a Dorado, Azul Hielo, Verde Pino o Madera.
* **Transiciones Cinemáticas:** Movimientos de menú y efectos de selección más suaves y envolventes.

## 🎁 Cómo instalar en Kino TV
1. Abre tu aplicación de **Kino TV**.
2. Ve a la sección de **Plugins**.
3. Añade un nuevo plugin y pega el enlace directo (Raw) del archivo `kino-plugin.json` de este repositorio.
4. Finalmente, ve a **Ajustes > Apariencia** y selecciona **Navidad** para activarlo.
